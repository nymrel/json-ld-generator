Questions, answered plainly

Before you ask

Is my data safe?

Generated or pasted JSON-LD is processed locally and may be stored in your browser. Product values are not attached to network requests. The hosted page also loads aggregate Vercel Web Analytics.

Do I need to know JSON to use this?

No. Pick a schema type, fill in plain fields, and the tool writes correct JSON-LD for you. You only need to know JSON if you want to.

How do I add the code to my page?

Copy the generated script block and paste it anywhere inside your page's <head>. Google and AI assistants read it automatically — no other setup.

What does the Check mode actually check?

It confirms your JSON is valid, has @context and @type set, and has the fields search engines expect for that type — like offers.price on a Product or acceptedAnswer.text on an FAQPage.

What do I get with Pro?

The Pro studio opens on this page — all 10 schema types, saved presets, and bulk checking — and you also download the whole thing as one .html file that runs offline, forever, with no account.
